# Quiver

[HID Remapper](https://github.com/jfedor2/hid-remapper) を入れたボードを、Windows から設定するためのアプリです。
マウスとPCの間にボードを挟み、マウスの動きを加工したり、キーボード・マウスをコントローラーの入力に変えたりできます。

## できること

- **揺れ**：ボタンを押している間、カーソルを細かく揺らす（揺れ幅・速さ・ランダムさ・方向を調整、軌跡のプレビュー付き）
- **コントローラー**：キーボード・マウスをゲームパッドの入力に割り当てる（Xbox風の配置図、ホイール上下、マウス→スティックの細かい調整）
- **切り替え**：専用ファームなら、切り替えキーでキーボード・マウスとコントローラーを挿し直しなしに瞬時に切り替え
- **自動切り替え**：画面に参考画像と同じ場面が映ったら、モードを自動で切り替え
- **外部ソフトから操作（API）**：ほかのソフトから座標を送って、カーソルを本物のマウス入力として動かす

## 必要なもの

- HID Remapper が動くボード（作者の環境は Waveshare RP2040-PiZero）
- USB-C → USB-A 変換アダプタ、USBハブ（ワイヤレスマウスのレシーバーによってはハブが必要）
- Windows 10 / 11

```
PC ──(USB)── [USB] RP2040-PiZero [PIO-USB] ── 変換アダプタ ── USBハブ ─┬─ マウスのレシーバー
                                                                    └─ キーボード
```

## 使い方

1. ボードにファームを書き込む（BOOTボタンを押しながらPCにつなぎ、出てきたドライブに `.uf2` をドラッグ）
   - 揺れだけなら公式の HID Remapper ファームで動きます
   - 切り替え・外部ソフト操作を使うなら [firmware/](firmware/) の専用ファームを書き込みます
2. [Releases](../../releases) から `Quiver-*-win.zip` をダウンロードして解凍し、`Quiver.exe` を起動
3. ボードをつなぐと自動で接続されます。設定を変えたら「デバイスに書き込む」

## 開発

```
npm install
npm start          # 起動
npm run dist       # Windows 用の zip を dist/ に作る
```

| ファイル | 内容 |
|---|---|
| `main.js` / `preload.js` | Electron のメイン処理（WebHID の許可、画面キャプチャ、トレイ） |
| `api.js` | 外部ソフト用のローカルAPI（127.0.0.1 のみ） |
| `src/remapper.js` | HID Remapper との通信（設定の書き込み、モニター、移動命令） |
| `src/expr.js` | 揺れの式の生成とプレビュー用の計算 |
| `src/controller-data.js` | コントローラーの割り当て、マウス→スティックの式 |
| `src/app.js` / `controller.js` / `autoswitch.js` / `api-ui.js` | 各画面 |

## 注意

オンラインゲームでマクロや自動操作を使うと、規約違反として処罰（BAN）の対象になることがあります。オフラインのゲームや、自分のアプリでの利用にとどめてください。
